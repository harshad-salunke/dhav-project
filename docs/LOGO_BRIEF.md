# DHAV — Logo Design Brief & AI Prompt Pack

> Hand this file to any AI image platform (Ideogram, Midjourney, DALL·E 3, Adobe Firefly, Leonardo, Recraft) to generate the DHAV app logo.
> **Read "How to use this file" at the bottom first** — AI tools are bad at spelling, so there's a trick to getting clean results.

---

## 1. Brand snapshot

| | |
|---|---|
| **Name** | DHAV (धाव — Marathi for *"run / dash / sprint"*) |
| **What it is** | A hyperlocal **kirana** (neighbourhood grocery) delivery app for **Pune** |
| **Tagline** | *Apni Dukaan, Apke Darwaze Tak* — "Your shop, to your doorstep" |
| **Promise** | Fast, trustworthy, local — your corner store, delivered in minutes |
| **Audience** | Everyday Indian households in Pune; all ages; mobile-first |
| **Personality** | Friendly, energetic, dependable, modern but desi-rooted, fast |
| **One-word feel** | **Speed** (the name literally means "run") |

The logo should feel **fast, friendly, and trustworthy** — a modern Indian delivery brand, not a cold tech startup.

---

## 2. What the logo must do (use cases)

This is **one mark used everywhere**, so it must survive every size and surface:

- 📱 **App icon** — sharp and recognisable at 48×48 px on a phone home screen
- 🏪 Splash screen, in-app header, invoices
- 👕 **T-shirts / delivery-rider uniforms** — bold, single-or-two-colour print
- 🛍️ **Shopping bags / tote bags / packaging tape**
- 📦 Boxes, stickers, scooter delivery-box decals
- 🪧 Signage, banners, social media avatar

**Therefore it MUST be:**
- ✅ **Simple** — readable as a tiny silhouette
- ✅ **Vector / flat** — crisp at any scale, no fine detail or gradients that muddy when small
- ✅ Work in **full colour, solid one-colour, all-white, and all-black**
- ✅ Have a strong **icon/symbol** that stands alone (the app icon = symbol only, no text)
- ✅ Centered, on a plain background, lots of clean space around it

---

## 3. Logo structure to deliver

Generate these as separate pieces (ask the AI for each):

1. **The symbol / icon** (primary) — a standalone mark. This becomes the **app icon**.
2. **The wordmark** — "DHAV" in a clean, bold custom-feeling typeface.
3. **The lockup** — symbol + "DHAV" together (horizontal and stacked).

> The **symbol is the hero**. The wordmark can be set later in a real font if the AI misspells it (see tips at the end).

## 4. Colour palette (use these exact hex codes)

| Role | Colour | Hex |
|---|---|---|
| **Primary — DHAV Blue** | Bright trustworthy blue | `#1E88E5` |
| **Deep — Midnight Navy** | Dark backgrounds / contrast | `#0A1F3D` |
| **Accent — Delivery Purple** | Signature (the brand's scooter colour) | `#7C3AED` |

| **Light — Warm White** | Background / knockout | `#FAFAF7` |

**Recommended hero treatment:** a **blue → purple gradient** (`#1E88E5` → `#7C3AED`) on the icon, with flat solid versions for print.
Keep it to **2–3 colours max**. Avoid rainbow / overly complex palettes.

## 5. Creative direction & concept ideas

Pick **one** clear idea — the best logos express a single concept. Strong directions for DHAV:

- **A. "D in motion"** *(recommended)* — a bold geometric letter **D** with a built-in **speed/dash** cue (a forward swoosh, motion lines, or a leaning silhouette) that nods to *dhav = run*. Modern, ownable, perfect app icon.
- **B. "D + kirana bag / leaf"** — the letter **D** merged with a shopping bag or a fresh leaf, signalling local groceries delivered.
- **C. "D + location pin"** — the **D** forming or holding a map **pin**, signalling *hyperlocal*.
- **D. "Speedy scooter mark"** — a minimal, iconic delivery-scooter glyph inside a rounded squircle (matches the purple scooter in the app). Friendly and literal — keep it ultra-simple so it scales.

**Style:** flat vector, geometric, rounded corners, bold weight, confident negative space. Think modern delivery/fintech app icons — clean, app-store ready.

## 7. Negative prompt / avoid list

Avoid: text misspellings, photorealism, 3D renders, drop shadows, bevels, glossy
web-2.0 effects, gradient mesh noise, clip-art look, overly intricate detail,
more than 3 colours, stock-photo vegetables, busy backgrounds, watermarks,
generic globe/cart icons, anything that turns into mush when shrunk to 32px.

## 9. How to use this file (important)

1. **Best platforms:**
   - **Ideogram** → best at rendering the word **DHAV** correctly. Use for lockups (Prompt 2).
   - **Midjourney / Leonardo / Firefly** → best-looking *icons*. Use for the symbol (Prompts 1, 3, 4).
   - **Recraft** → can output real **vector/SVG** directly — great for the final master.
2. **AI can't spell reliably.** Generate the **icon without text**, then add "DHAV" yourself in a clean bold rounded font (e.g. *Poppins SemiBold, Montserrat ExtraBold, or Inter Black* — matches the app). This guarantees a perfect wordmark.
3. **Generate the icon alone first** (Prompt 1). Once you love a symbol, build the lockup around it.
4. **Always vectorise the winner** (SVG) before printing on shirts/bags — raster AI output blurs at large print sizes.
5. Make **4–8 variations**, shrink each to 32 px on screen, and keep only the ones still readable tiny. That test alone picks the winner.
